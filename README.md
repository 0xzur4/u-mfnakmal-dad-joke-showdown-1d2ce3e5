One original dad joke, told out loud at the dinner table: "I told my son the calendar's days are numbered. He said, 'Dad, that's literally how calendars work.'" A setup with a straight face, then the turn lands on the double meaning of "days are numbered" — doomed, and literally numbered. One hundred characters, one line, no setup wasted.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the joke to `out/entry.txt`.
